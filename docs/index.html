Features

Everything on screen is something you chose

Home goes home

The Home button opens Glass from anywhere, even inside Netflix or Fire TV Settings. A Fire TV Home tile opens Amazon's screen when you want it.

Now Playing pill

Album art, title and artist for whatever is playing on Spotify or YouTube. Press select to pause, Menu to jump into the app.

Tiles go where you put them

Press Menu on any tile, choose Move, and carry it with the arrows. Up from the grid puts an app in your four slot dock.

A Settings menu that behaves

Opens Fire TV Settings directly instead of bouncing through Amazon's home first, and holds the screensaver timer and update options.

Updates on your terms

Glass checks GitHub once a day and asks before installing anything. Switch the check off during setup or later in Settings.

Optional debloat

A script disables Amazon's telemetry, ad services and preloaded apps. Nothing is uninstalled, and one command turns it all back on.

Your TV should feel like furniture, not a billboard. Glass gives the screen back to the shows you picked.

Koi pond screensaver

A pond that follows the sky outside your window

After 2 to 30 idle minutes, never while something plays, a new pond fills the screen. Fish, lily pads and flowers change every time. The light follows your local sunrise, sunset and weather, and one pond in twenty hides a giant gold or platinum koi.

Pond by nagomi from Mayank Kadam, adapted for TV.

Setup

Installed in three steps, about ten minutes

You need a computer on the same network as the stick, with Android platform tools for the adb command.

Find it in Settings, My Fire TV, About, Network. It stays in this page and is never sent anywhere.

  1. 1

    Turn on ADB debugging

    In Settings, My Fire TV, About, select the device name seven times to unlock Developer Options. Then switch on ADB debugging there.

  2. 2

    Install glass.apk

    Download glass.apk, open a terminal in that folder and run these. Accept the Allow USB debugging prompt on the TV.

    adb connect {ip}:5555
adb -s {ip}:5555 install -r -g glass.apk
  3. 3

    Give Glass the Home button

    These let Glass catch the Home button, show Now Playing and install its own updates. Then press Home on the remote.

    adb -s {ip}:5555 shell settings put secure enabled_accessibility_services com.ivantrj.glasslauncher/com.ivantrj.glasslauncher.HomeButtonService
adb -s {ip}:5555 shell settings put secure accessibility_enabled 1
adb -s {ip}:5555 shell cmd notification allow_listener com.ivantrj.glasslauncher/com.ivantrj.glasslauncher.MediaListener
adb -s {ip}:5555 shell appops set com.ivantrj.glasslauncher REQUEST_INSTALL_PACKAGES allow

Prefer to let a coding agent do it?

Claude Code, Codex or Cursor can run the whole install while you hold the remote. The README has a ready prompt that asks before every change.

FAQ

Questions before you install

Do I need to root my Fire TV Stick?

No. Glass installs over ADB debugging, which Fire OS offers in Developer Options. Nothing is rooted or unlocked.

Can I undo it?

Yes. On the TV, turn off Glass Home button in Settings, Accessibility. On a computer, the restore script also turns any disabled Amazon packages back on.

Which Fire TV Sticks does it work on?

It is tested on Fire OS 8. It installs on Fire OS 7 and 6 too, but nobody has reported back from a real stick on those yet, so the Home button takeover and the koi pond are unconfirmed there.

Will my apps still work?

Yes. Glass is only a home screen. Netflix, YouTube, Spotify and everything else open exactly as before.

Does it remove Amazon's ads everywhere?

The sponsored rows live on Amazon's home screen, which you stop seeing. Ads inside other apps come from those apps and stay.

Does Glass collect any data?

No analytics at all. The pond looks up your rough location from your IP with ipwho.is and the weather from Open Meteo, and Glass checks GitHub once a day for updates unless you switch that off.

Does it cost anything?

No. Glass is free and open source. If it makes your evenings calmer, there is a Ko-fi page.

How smooth is the koi pond?

On a Fire TV Stick 4K Max it runs at about 20 to 23 frames per second. Older sticks may run it slower.
